# 数据分析作品集 · JessiesZ

应用统计学本科在读，关注**消费者行为、市场研究与数据支持决策**。这里收录四个完整的课程/竞赛项目，覆盖从**问卷设计、数据清洗、统计建模到结论输出**的全过程，以及数据库系统设计与深度学习风控建模。

## 项目一览

| # | 项目 | 类型 | 主要方法 | 产出 |
|---|---|---|---|---|
| 01 | [数学建模竞赛平台数据库设计](./01-database-course-design) | 数据库系统 / 全栈 | E-R 建模、SQL Server、存储过程、FastAPI、Vue 3 | 建库脚本、后端 API、前端页面、答辩 PPT |
| 02 | [45°青年养生茶消费心理与市场机会](./02-tea-consumer-research) | 消费者研究 | 问卷（1400 份）、PEST、SOR/SICAS/ACSI、聚类、Logistic 回归 | 研究报告、附录、答辩 PPT |
| 03 | [Z 世代二手市场现状与需求分析](./03-secondhand-market-research) | 市场研究 | 问卷 + 深度访谈、SICAS/ACSI、相关/回归、K-means | 研究报告、附录、答辩 PPT |
| 04 | [基于 FL-GRU 的信用卡违约预警](./04-gru-credit-default) | 机器学习 / 风控 | 数据清洗、BorderlineSMOTE、双层 GRU、Focal Loss、阈值寻优 | 脱敏报告、可复现代码、合成样本 |

## 技能

- **数据处理**：Python（pandas / numpy）、SQL（SQL Server）、Excel
- **统计分析**：描述统计、交叉分析、相关与回归、聚类（K-means）、结构方程模型
- **机器学习**：TensorFlow / Keras、GRU、Focal Loss、BorderlineSMOTE、阈值寻优
- **可视化与呈现**：ECharts、Excel 图表、PPT 汇报
- **工程**：FastAPI、SQLAlchemy、Vue 3、Element Plus、Git
