# 旧物新生：生活类二手市场现状与需求分析——以 Z 世代为例

## 研究问题
Z 世代（1995–2009 年出生）正成为二手交易的重要增量人群。本研究关注：他们为什么买/卖二手？当前二手市场的痛点是什么？平台与商家可以如何改进？

## 方法
- **二手数据**：行业报告、政策文件、平台公开数据
- **问卷调研**：面向 Z 世代消费者的线上问卷
- **深度访谈**：二手平台用户、个体卖家、相关从业者
- **分析框架**：SICAS 消费行为模型、ACSI 顾客满意度模型
- **统计方法**：描述统计、交叉分析、相关分析、回归分析、K-means 聚类

## 主要发现
- Z 世代二手消费动机以**性价比、环保理念、猎奇与社交**为主，且存在明显人群分层
- 影响购买意愿的关键因素：信息透明度、沟通效率、平台保障、商品描述真实度
- 影响满意度的关键因素：感知质量与感知价值
- 建议：规范平台运营、强化内容与社区、完善鉴定与信用体系、拓展校园与下沉市场
