# 桦语北境：非遗桦树皮画品牌升级与代际传承

> 创客组商业计划书的项目化整理：以鄂伦春族桦树皮画为对象，做品牌升级、产品分层、渠道与财务测算。

## 项目背景

桦树皮画是北方渔猎民族（鄂伦春族、赫哲族等）的传统技艺，2006 年入选首批国家级非遗名录。当前行业面临四个结构性痛点：

1. **认知度低**：近半数本地受访者从未听说过桦树皮画，省外认知不足 6%
2. **产品单一**：传统装饰画占 60%，与年轻消费场景脱节
3. **传承断层**：传承人 50 岁以上占 70%，完整掌握技艺者不足 50 人
4. **渠道低效**：80% 销售依赖景区/展会，线上仅 20%

「桦语北境」的定位是：**把非遗从“博物馆展品”变成“可触摸的日常文化符号”**，通过品牌化、产品分层与数字化渠道，实现代际传承与商业闭环。

## 市场与定位

| 指标 | 数据 |
|---|---|
| 桦树皮画市场规模（2023） | 2.8 亿元，2018–2023 年均增速约 18.5% |
| 全国非遗产品线上交易额（2023） | 突破 1200 亿元，同比 +23% |
| 行业结构 | 传统装饰画 60%、文创衍生 30%、DIY 10% |
| 目标客群 | 高收入收藏人群、中等收入家居/文创人群、学生体验人群 |
| 价格带 | 引流层 50–100 元、主力层 300–3000 元、高端层数万元、服务层按项目计价 |

## 商业模型

```
文化 IP（珠勒都很纹样 / 取皮不伤树）
        ↓
产品矩阵：DIY 材料包 → 文创衍生 → 装饰画 → 高端定制
        ↓
渠道：小程序商城 + 直播电商 + 景区快闪 + 线下体验课
        ↓
收入：产品销售 + 体验课程 + IP 授权 + 平台佣金/分成
```

## 代码说明

计划书本身不含代码，这里补的是一套**商业分析工具**，用于把计划书里的假设变成可调的模型：

- `market_model.py`
  - 按 2.8 亿元基数和 18.5% 增速测算 TAM/SAM/SOM
  - 四档产品（DIY / 文创 / 装饰画 / 高端定制）的量价拆分
  - 三年营收、毛利、净利、盈亏平衡点
  - 悲观/基准/乐观三情景
- `ahp_brand.py`
  - 文化 IP、产品创新、渠道、数字化四项准则的 AHP 权重与一致性检验
  - 对三个品牌升级方案打分排序

```bash
pip install -r requirements.txt
python src/run_all.py
```

> 所有参数均为**示例假设**，用于演示模型结构，不代表计划书承诺的实际经营结果；真实测算需替换为调研数据。
