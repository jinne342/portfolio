# The Medal Tally: Unraveling the Olympic Champions

> 2025 年 MCM/ICM C 题论文的项目化整理：用 GBDT 预测奥运奖牌榜，结合 AHP、Mann-Whitney U 检验与 Herfindahl 指数分析优势项目与「名帅效应」。

## 项目背景

奥运会奖牌榜是竞技体育、人口规模、经济投入、主办优势等多因素共同作用的结果。本文基于历届奥运历史数据，建立奖牌榜预测模型，并回答四个问题：

1. 如何评估各国运动员水平，并预测 2028 年洛杉矶奥运会奖牌榜？
2. 2028 年会有多少国家首次获得奥运奖牌？该预测的可信度如何？
3. 主办国增减项目会如何影响奖牌分布？
4. 如何识别「名帅效应」，它能为成绩带来多大提升？

## 方法

| 模块 | 方法 |
|---|---|
| 运动员水平 | 运动员质量评价模型（Athlete Quality Evaluation Model） |
| 奖牌预测 | 梯度提升决策树（GBDT），拟合优度 R² = 0.81 |
| 首次夺牌 | 基于 GBDT 预测 + 归一化均方误差换算概率 |
| 项目集中度 | Herfindahl 指数（HHI）衡量各国奖牌的项目集中度 |
| 名帅效应 | AHP 层次分析法 + Mann-Whitney U 检验（胜率突变点） |

### 主要结论（报告原文）

- 2028 年奖牌榜预测模型 **R² = 0.81**
- 预计 **12 个国家**在 2028 年首次获得奥运奖牌，预测实现概率约 **84%**
- 主办国在**新增项目**上具有明显优势；减少项目时，主办国在这些项目上的竞争力反而下降
- 名帅效应可带来约 **11.51%** 的成绩提升；建议韩国跳水、日本网球、菲律宾游泳尝试引进名帅

> 以上为论文原文结论；本仓库代码用合成数据演示同一套方法，运行结果会不同。


## 说明与局限

1. **数据为合成样本**：原始奥运数据未随论文提供，仓库用同结构数据演示方法；复现论文数值需要完整历史数据（1896–2024）。
2. **R² = 0.81 是论文在原始数据上的结果**，合成数据上会偏低或偏高。
3. 论文的「名帅效应」依赖胜率突变点识别，存在主观性；AHP 权重也带主观成分，这是论文在局限性章节中承认的问题。
4. 论文为团队参赛作品，页眉团队编号已替换为 `XXXXXXX`，作者元数据已清空。
