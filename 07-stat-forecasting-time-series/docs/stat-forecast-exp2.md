简单移动平均法是利用时序前 T 期的平均值作为下一期预测值的方法，其 数据存储量比简单平均法少，只需一组 T 个数据。T 是平均的期数，亦即移动 步长，其作用为平滑数据，其大小决定了数据平滑的程度。T 越小，平均期数 少，得到的数据越容易保留原来的波动，数据相对不够平滑;T 越大即移动步长 越长，得到的数据越平滑。 

简单移动平均预测实际上是通过当期预测误差修正当期预测值得到下一期 的预测值。这是简单移动平均法的一个 优点 ，通过误差不断修正得到新的预测 值。其 不足 在于往往存在滞后问题，即实际序列已经发生大的波动，而预测结 果却不能立即反映。

**4.** 模型选择 

- （ **1** ）图像识别法 

图形识别法是从实际时间序列的数据出发选择模型的方法。该方法将时间 序列的数据绘制成以时间 t 为横轴，时序观察值为纵轴的曲线图，观察其变 化，并与各类函数曲线模型的图形进行比较，选择较为合适的模型。实际的观 测对象往往无法通过图形直观确认为某种模型，所以，一般初选几个模型，然 后再通过模型分析确认合适的模型。 

## （ **2** ）阶差法 

阶差法是从模型的特点出发，观察时间序列的特点，并将其与各类模型阶 差的特点比较以选择适宜模型的方法。 

## **5.** 模型分析评价 

模型分析评价有两个方面:一是模型对历史数据的拟合，二是型对未来趋势 的表现。若所选的趋势模型对历史数据拟合较好，又符合其未来的发展趋势， 则可以直接用于预测。

# 七、实验收获 

本次实验以消费品指数时间序列为研究对象，运用移动平均、一次指数平 滑 布朗一次平滑等经典时序预测模型完成建模 计算与对比分析。通过纵向观 察预测序列随时间的变化趋势 横向对比不同参数与模型的预测误差，我对时间 序列平滑预测方法有了更加完整 落地的理解。 

从实验结果来看，移动平均模型存在显著的滞后特性。窗口长度越大，预 测曲线越平稳，对随机噪声的过滤效果越好，但对序列拐点 短期突变的响应速 度越慢。窗口缩小后，模型灵敏度提升，预测值波动随之放大。一次指数平滑 受平滑系数$\alpha$调控，$\alpha$取值越大，近期观测值权重越高，模型对最 新信息的跟踪能力越强。结合 MAPE 误差指标综合评判，在本消费品指数数据 集下，$\alpha=0.7$的一次指数平滑模型平均相对误差最小，预测表现优于本组 其他模型。同时我也意识到，这类平滑方法均建立在历史信息加权的基础上， 属于依赖过往数据的外推方法，面对序列突发跳变时难以快速捕捉异动，存在 固有的局限性，仅适合趋势相对稳定 无剧烈突变的短期预测场景。 

在动手实现与数据分析的过程中，我跳出了课本上抽象的公式，真切体会 到参数选择不是简单试错，而是在平滑降噪和趋势跟踪之间做权衡。起初我只 关注数值计算是否正确，忽略了误差背后的模型机理。在逐行核对预测表 对比 同一时点不同模型输出 梳理 MAPE 差异的过程中，我慢慢读懂每一条曲线 每 一组误差数字背后的含义。横向对比让我学会定量评价模型优劣，纵向时序观 察教会我从动态视角审视预测结果，而不再孤立看待单个预测值。 

这次实验也让我收获了严谨的科研思维。时序预测没有万能最优模型，不 存在一套参数适用于所有序列，模型选择必须贴合数据本身特征。数据清洗 结 果制表 对比论证 误差解释，每一步都需要耐心，一个微小的计算偏差就会影 响后续全部对比结论。我也认识到经典时序模型的边界。它们简洁易用，但能 力有限，若要应对更复杂 非线性 带有多重周期的序列，还需要学习更加进阶 的时序方法。 

此次实验不只是一次课程任务，更是一次理论联系实践的历练。我巩固了 时间序列分析的基础理论，熟悉了模型对比 误差评价的研究范式，培养了定量 分析 客观论证的习惯。未来再做预测类研究时，我会先分析序列特征，合理选 择模型与参数，重视模型假设与适用条件，理性看待预测结果，不盲目迷信模 型输出。这份踏实求证 审慎分析的思维，也会成为后续统计学学习与科研实践 中重要的积累。

**def** moving_average_pred(series, window): n = len(series) pred = np.full(n, np.nan) **for** i **in** range(window, n): pred[i] = np.mean(series[i-window:i]) **return** pred df[ **"MA3"** ] = moving_average_pred(y_series, window=3) df[ **"MA5"** ] = moving_average_pred(y_series, window=5) df[ **"MA12"** ] = moving_average_pred(y_series, window=12) mape_ma3 = calc_mape(y_series, df[ **"MA3"** ].values) mape_ma5 = calc_mape(y_series, df[ **"MA5"** ].values) mape_ma12 = calc_mape(y_series, df[ **"MA12"** ].values) print( **"=====** 移动平均 **MAPE** 结果（ **%** ） **====="** ) print( **f"T=3  MAPE = {** mape_ma3 **}"** ) print( **f"T=5  MAPE = {** mape_ma5 **}"** ) print( **f"T=12 MAPE = {** mape_ma12 **}"** ) **def** single_exp_smooth(series, alpha): n = len(series) s = np.zeros(n) s[0] = series[0] pred = np.full(n, np.nan) **for** i **in** range(1, n): s[i] = alpha * series[i-1] + (1-alpha)*s[i-1] pred[i] = s[i] **return** pred alpha_list = [0.3, 0.5, 0.7] **for** a **in** alpha_list: colname = **f"SES_{** a **}"** df[colname] = single_exp_smooth(y_series, alpha=a)
