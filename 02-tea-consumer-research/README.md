# “半卷半躺”的养生仪式：45°青年养生茶消费心理与茶产品创新机会研究

## 研究问题
“45°青年”指在“内卷”与“躺平”之间寻求平衡的年轻群体。本研究关注：他们的养生茶消费动机是什么？消费心理与偏好呈现哪些分层？茶品牌可以抓住哪些产品与沟通机会？

## 方法
- **问卷调研**：发放 1400 份，回收有效问卷 1274 份，有效率 91%
- **理论框架**：PEST 宏观分析、SOR 模型、SICAS 消费行为模型、ACSI 顾客满意度模型
- **统计分析**：描述统计、交叉分析、信效度检验、聚类分析（K-means）、Logistic 回归、结构方程模型
- **质性补充**：对养生茶消费者与从业者进行深度访谈

## 主要发现
- 45°青年的养生茶消费呈现明显的**分层特征**，可分为尝鲜型、功能型、社交型等群体
- 购买意愿主要受**感知价值、社交影响、产品形态与价格敏感度**影响
- 品牌机会集中在：场景化产品设计、便携形态、内容化沟通与社群运营
