# 一页纸：电商用户行为分析

**数据**：UCI Online Retail 子集，66,764 笔有效交易，1,150 位客户，2010-12 至 2011-01（8 周），销售额 £1.35M。

## 三个结论

1. **收入高度集中**：Top 20% 客户贡献 69.6% 销售额；195 位「重要价值客户」贡献 33.9%。
2. **复购率低、首周关键**：整体复购率 36%，64% 客户只买一次；首购后第 1 周留存 10.1%，第 3 周跌到 6.8%。
3. **地区集中**：英国 87.3%，荷兰 2.6%、爱尔兰 2.2%；跨境是增量但需验证。

## 三个建议

| 优先级 | 动作 | 目标 |
|---|---|---|
| P0 | 56 位「重要挽留客户」7 天内一对一召回 | 挽回 £88.6k 高风险收入 |
| P1 | 新客首单后 7 天内发第二单券 | 首周留存 10% → 15% |
| P2 | 荷兰/爱尔兰小规模跨境测试 | 验证客单价与物流成本 |

## 方法

- 清洗：剔除取消/退货/0 价格/缺失 CustomerID，DuckDB 建 `transactions` 与 `sales` 视图
- SQL：RFM（NTILE）、周 cohort（DATE_DIFF）、复购间隔（LAG）、窗口环比
- 看板：Streamlit + Plotly，4 个页签

## 局限

8 周数据，无法看年度季节性；无曝光/点击事件，不做漏斗；单笔 £77k 异常订单需单独处理。
